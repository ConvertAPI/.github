ConvertAPI is a REST API that converts Word, Excel, PowerPoint, HTML and image files to PDF, turns PDF into Word, Excel or images, and merges, splits, compresses and OCRs PDF files.

**Free trial: 250 conversions, no credit card.** [Get your API token](https://www.convertapi.com/a/signup?ReturnUrl=%2Fa%2Fauthentication&utm_source=github&utm_medium=referral&utm_content=org-profile)

## Tools

- [convertapi-mcp](https://github.com/ConvertAPI/convertapi-mcp): an MCP server that lets AI assistants and agents convert files with ConvertAPI. A hosted version runs at https://mcp.convertapi.io ([docs](https://www.convertapi.com/docs/mcp-server)).
- [convertapi-cli](https://github.com/ConvertAPI/convertapi-cli): convert files from the command line on Windows, macOS and Linux ([docs](https://www.convertapi.com/integrations/libraries/cli)).
- [convertapi-powershell](https://github.com/ConvertAPI/convertapi-powershell): a PowerShell wrapper for the ConvertAPI REST API.
